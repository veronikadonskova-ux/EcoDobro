# ЭкоДобро

**Платформа экологического волонтёрства и просвещения Нижнего Новгорода**

Интерактивный сайт, который помогает людям вести более экологичный образ жизни через геймификацию, полезные задания и удобные инструменты.

## Основные возможности

- Интерактивное дерево роста (мотивация через геймификацию)
- Колесо фортуны с экологическими заданиями
- Карта SOS — сообщение и решение экологических проблем
- Личный кабинет с отслеживанием прогресса
- Разделы: Волонтёрство, Личный вклад, Пункты приёма, Мероприятия
- Авторизация, формы заявок и календарь событий

## Технологии

- **Backend**: PHP, MySQL
- **Frontend**: HTML5, CSS3, JavaScript
- **Геймификация**: SVG-анимации, localStorage
- **Хостинг**: TimeWeb

## Структура проекта

- `public/` — основные файлы сайта (web root)
- `database.sql` — структура базы данных
- `docs/` — документация и скриншоты
- `README.md` — описание проекта

##  Как запустить локально

1. Склонировать репозиторий
2. Импортировать `database.sql` в phpMyAdmin
3. Настроить подключение к базе данных
4. Разместить папку `public` в корне веб-сервера
